# 开放问题清单

## 1. 使用方式

本清单只保留尚未决定、会影响后续设计或实现的问题。问题解决后应更新相关业务文档或 ADR，并从“开放”改为“已解决”，不只在聊天中留下结论。

优先级含义：`P0` 阻塞下一阶段，`P1` 必须在对应模块开发前解决，`P2` 可以等待基线或后续范围确认。
