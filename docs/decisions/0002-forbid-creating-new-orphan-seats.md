# ADR-0002：默认禁止一次选座制造新的孤座

- 状态：已接受
- 日期：2026-09-24

## 背景

座位是具有空间关系的库存。一次购买如果在连续可售座位中留下一个孤立空位，会降低剩余库存满足多人购票的能力。但如果禁止所有孤座，系统中原本已经存在的孤座将无法售出，而且过道、区域和票档边界可能导致错误判断。

## 备选方案

### 方案 A：只把孤座作为推荐评分

用户限制少，但手动选座仍可制造大量孤座，不能稳定保护座位库存，不采用为默认规则。

### 方案 B：禁止存在任何孤座

约束过强，会导致已有孤座无法购买，也容易在复杂布局中误判，不采用。

### 方案 C：禁止本次选择制造新的孤座

比较选座前后的连续可售分段；拒绝新增只包含一个可售座位的分段，但允许购买选座前已经存在的孤座。

## 决策

采用方案 C，并允许场次明确配置为允许制造孤座。

- 座位分段限定为同一区域、同一排、同一票档且不跨过道。
- 不可售位、过道、区域边界和票档边界会切断连续关系。
- 系统推荐不得产生新孤座。
- 手动选座在最终锁座时执行同样的校验。
- 已经存在的孤座可以单独购买。
- 推荐通过不代表锁座必然成功；锁座时必须根据最新座位状态重新校验。

## 影响

- 规则能体现票务库存与普通数字库存的区别，并减少可售座位碎片化。
- 用户可能看到座位可售但无法按当前组合购买，界面需要返回明确的业务错误，而不是笼统失败。
- 必须覆盖排首、排尾、过道、不可售位、票档边界、已有孤座和并发状态变化等测试。
- 若后续需要根据临近开场时间动态放宽规则，应作为新的业务决策处理，首版不自动切换。
