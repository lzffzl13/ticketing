# ADR-0007：一致性只读座位查询与实时连座推荐

- 状态：已接受，项目负责人于 2026-10-05 确认
- 日期：2026-10-05（Asia/Shanghai）

## 业务问题与不变量

消费者需要看完整座位布局并获得可解释的候选。场次销售状态、票档开关和座位状态来自不同查询，若查询期间配置改变，不能将多个版本拼在一起。查询结果只说明读取时的状态，不得当作资源预留。

连座与孤座规则沿用 ADR-0002：同区域、同排、同票档、连续座号且不跨过道；禁止新增孤座、允许既有孤座，场次可以关闭限制。库存状态与销售开关独立。

## 备选与决定

采用一个只读 REPEATABLE READ 本地事务读取场次、票档和座位，不加行锁，不写库存。独立查询更简单但可能混合版本；查询时锁库存会无收益地阻塞购买，因此不采用。

采用实时分段扫描和窗口枚举作为算法基线。位图与预计算可能改善耗时，但增加更新和失效成本，当前没有基线支持引入。完整布局先按区域/排/座号排序并切连续 AVAILABLE 段，再筛选区域和启用票档；不因提前删除边界座位而错误拼接。

候选先按区域展示顺序排序，同区按候选中心到区域边界框中心的距离平方排序，再按排排序、排标签、起始座号、ID 破同分；区域同展示顺序用代码和来源区域 ID 破同分。区域中心由全部快照计算，不随候选筛选或库存变化移动。坐标是每区的逻辑坐标，不代表实际米数。首版不增加位置偏好或非连座自动推荐。

inventory 的纯选座规则供推荐与第四周最终锁座复用。单连续段的候选只需判断左右余数是否为 1；手动自由选座按整组比较前后孤座的具体身份，不能只比较数量或逐座判断。

## 边界和后续

接口、诊断、参数和验证计划见[评审方案](../design/week-03-seat-recommendation-review.md)。返回条数 1–20 是展示限制，不增加购票人数上限。未知场次 404、非法筛选 400、非售卖场次推荐 409、无候选 200 空数组。

沿用本机演示 API；Q-05 令牌机制仍待个人数据/交易鉴权前确认，不把只读 API 宣称为已实现用户鉴权。第三周不实现锁座、订单或候选过期时间；第四周下单必须在最终写事务中重新校验最新状态，并解决并发孤座和整组原子性。
