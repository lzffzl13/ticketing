- 新增本人 `GET /api/orders/{orderId}/tickets/{ticketId}/credential` 与 `/qrcode`，分别返回凭证文本与 PNG，均 no-store。角色和归属来自原登录上下文；他人/跨订单票统一 404，非 VALID 或到入场截止返回 409。
